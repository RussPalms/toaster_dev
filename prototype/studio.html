Cheat sheet

Mini-notation (inside "double quotes")

"bd sd hh sd"steps share one cycle (one bar) evenly
"hh*8"   "bd/2"repeat faster / play slower
"bd [sd sd]"[ ] squeezes a group into one step
"<c e g>"one value per cycle, taking turns
"bd, hh*4"comma plays layers at the same time
"~"a rest
"bd(3,8)"Euclidean rhythm: 3 hits spread over 8 steps
"hh?"   "bd@3"maybe play it / make it 3 steps long
"hh:2"pick variation 2 of a sample

Sound

s("bd").bank("RolandTR909")samples and drum machines
note("c3 e3")   n("0 2 4").scale("E:minor")pitches by name or by scale step
.s("sawtooth" | "supersaw" | "piano")synths and instruments
.lpf(800) .lpenv(2) .room(.5) .delay(.25) .gain(.8)filter, filter envelope, reverb, echo, volume
.attack(.01) .decay(.2) .sustain(.5) .release(.3)envelope
slider(900, 200, 4000)drag-able number right in the code
.fast(2) .slow(2) .rev() .jux(rev)time tricks
.sometimes(x => x.speed(2)) .degradeBy(.3)controlled randomness

Performing

$: patterneach $: block plays at the same time
_$: patternmute a block without deleting it
setcpm(140/4)tempo: bpm / 4
s("bev").slice(8, irand(8).segment(8))vocal chops: 8 slices, random order

.punchcard() (no underscore)draws full screen behind the code
.color("cyan magenta")color the highlights
